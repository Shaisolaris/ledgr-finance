# Ledgr

Personal finance mobile app UI with onboarding and transactions.

**[Live Demo](https://shaisolaris.github.io/ledgr-finance/)**

## Features

- Multi-step onboarding flow
- Transaction feed with categories
- Budget and insight cards
- Mobile app frame presentation

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
